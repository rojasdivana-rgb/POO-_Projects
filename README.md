### ⚡ Inicio Rápido

```bash
# Opción 1: Ejecución automática (RECOMENDADO)
ejecutar.bat          # Windows CMD
./ejecutar.ps1        # Windows PowerShell

# Opción 2: Compilación manual
cd src
javac -d ../bin -encoding UTF-8 *.java model/*.java process/ventas/*.java process/reportes/*.java repository/*.java ui/*.java utils/*.java
cd ..
java -cp bin Main
```
